# 角色蒸馏与沉浸式对话 · UI 改版概念稿 Brief

## 产品定位
一个 AI 角色模拟器：用户把任意文本素材「蒸馏」成有性格的 AI 角色，然后与之进行沉浸式对话。中文界面，移动优先，同时要兼顾桌面端侧边栏双栏布局。

核心场景：登录 → 角色市场浏览/搜索 → 角色卡片 → 进入沉浸式对话（人物对话/群聊/私信）→ 语音对话 → 蒸馏任务进度 → 主题切换 → 个人中心。

## 现状诊断（改版要解决的核心问题）
当前是「有主题、没设计系统」：

1. **没有字体层级 scale** — 大量 magic-value 字号（11px/12px/13px/14px/15px/16px/18px 散落各组件），没有 font-size token，更没有展示/正文/小字/注释的分级。
2. **没有间距 token** — padding/margin 全是散落的 magic-value。
3. **系统字体栈** — 没有任何字体个性，中文界面用的是浏览器默认。
4. **两套设计语言并存** — antd-mobile 组件（TabBar、Toast 等）与自定义 `.btn-*` 按钮/卡片是两套视觉语言，圆角、描边、阴影不统一。
5. **没有圆角一致性锁** — 组件圆角 4/8/12/16/999 混用，无规则。
6. **暗色模式对比度漂移** — 部分页面暗色下文字对比度不足，错误页曾有黑字沉底问题。
7. **状态反馈不完整** — loading/empty/error 三态在各页面实现不一致。

## 现有点位（必须在改版中保留的资产）
- **语义色 token 已经建好**：`--primary / --accent / --card-bg / --text-dim / --success / --danger / --warning / --on-danger`，共 6 套主题 × 亮/暗。改版要保留这套 token 命名和主题体系，只重构如何被消费。
- **共享 SVG 图标组件**（stroke=currentColor，统一 1.5~2 描边）已建成，改版沿用，不重新造。
- **移动端底部 TabBar**（首页/文本/群聊/我的）、**蒸馏任务悬浮球+进度条**、**语音按住说话** 这些功能形态不变。

## 目标产出
出一套完整改版概念稿（HTML/CSS 可交互原型），包含：

1. **设计系统层**：
   - 字体 scale（display/title/body/caption 分级 + 字号/行高 token）
   - 间距 scale（4 的倍数 token）
   - 圆角一致性锁（一套规则，明确「按钮=胶囊、卡片=16、输入框=8」这类规则）
   - 阴影/elevation（按层级 tint 到背景色）
   - 6 套主题在 token 层如何统一映射（亮/暗都覆盖）
2. **关键页面原型**：登录、角色市场（网格/列表）、角色卡片、沉浸式对话（聊天气泡、输入栏、语音）、群聊、私信、蒸馏任务进度条、主题设置、个人中心。
3. **一个明确的视觉方向**：给这个「AI 角色扮演」产品一个有性格的设计语言——不是通用 SaaS 灰，而是有情感温度、有叙事感的视觉风格，但保持克制、可落地。

## 设计约束
- 中文界面，正文用中文。
- 移动优先（390px 视口是主战场），桌面双栏是延伸。
- 不引入额外运行时依赖；原型用纯 HTML/CSS/少量 JS 即可，落地时前端是 React+Vite。
- 情感定位：沉浸式、有角色感、温暖克制。避免 AI 紫渐变、避免玻璃拟态堆砌、避免纯居中 Hero。可以偏向「对话/剧场」的气质——让用户感觉在和一个有性格的存在对话。
