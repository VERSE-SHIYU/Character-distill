```

```

`资料没发出去；错误日志：['Forward user profile to peer failed: Object of type function is not JSON serializable']`

1. ~~修复：`node_region` → `home_region`（一个词）。测试转绿。~~ **已做**：`web/routers/auth.py` 的注册路由改传 `home_region`；全仓 `forward_user_profile_to_peer` 调用点只此一处。
