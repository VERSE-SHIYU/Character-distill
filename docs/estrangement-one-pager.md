# 角色主动疏远 —— 一页设计（刻意未上线）

> Character-distill · 情感状态机系列的终点设计 | 基准: main@99667f3 | 状态: 设计冻结 v2（调研修订版），P1 影子模式为解冻条件

## 它是什么，为什么是我们

现有八个"巧思"（苏醒、重逢、目送、离线时刻、到访觉察、沉默、口癖、跨档流露）全是**角色对用户行为的反应**。主动疏远是发起权的反转：被持续冒犯的角色**主动**收回关系——好感缓降、语气持续变冷、一句道歉不能复原，要哄。有代价的关系才是真关系。

**差异化**：2025-26 学界密集批评伴侣 AI 系统性谄媚（Chu et al. 2025 对 17k 真实对话的实证：动态迎合并放大用户情绪，呼吁高风险重设计）；工业扫描显示 C.AI/Replika/Talkie/Chai/Janitor **无一实现主动疏远**——参与度 KPI 在结构上不允许角色冷落用户。本产品 BYOK、无续聊率绑架，是结构上唯一能做这件事的位置；与既有 anti-sycophancy 架构一脉相承。

## 状态机（前兆坡道版）

`normal → brewing → active → cooling → normal`

**进入**（8 轮滑窗任一，零新增 LLM 调用）：负向轮次≥4 且降幅≥12 / `psyche.triggers` 命中≥2 / 单轮触底且 guard≥75。达到阈值一半即进入 **brewing**：零数值改动，仅轻 prompt（回复稍短、热情稍减、不点破），窗口滑出自愈。每次雷点命中**当场**即有小反应（Fallout 4 分级 telegraphing 的验证做法）——疏远进入是已被看见的信号的收束，不是凭空爆发。

## 回暖曲线（"要哄"的数学形状）

```
好感│ 正常(clamp +5) ─╮ brewing: 语气微降,数值不动
    │                 ╲ active: 正向clamp收紧+1, 每轮被动-1
    │                  ╲______ floor = baseline−15（弹性形变，非断裂）
    │                         ╱ 解除: 连续N轮近乎零犯错+修复行为≥2次
    │                    ____╱  N: 大度4/一般6/记仇10; 高stage进入 +2
    │                   ╱ cooling: clamp仅+3, 3轮语气坡道滑回正常
    └────────────────────────────────────────────────→ 轮次
```

理论锚：信任不对称原理（Slovic 1993——负面冲击远大于正面，恢复慢于跌落）；三振疤痕（Esterwood & Robert 2023a——三次违背后任何修复策略均无法完全复原 → 同会话第 2 次疏远起 baseline 永久 -2，上限 3 次）；修复分型吃人格（2023b——感性角色吃道歉、理性角色吃解释，由 soft_spots 门控）；修复成功小幅超回 baseline+2（Tronick Still Face——破裂-修复循环深化依恋，做对了是留存资产而非风险）。

## 三个时刻（转折外显，过程克制）

持续的冷若无转折信号，用户只会归因"产品变笨了"。三个状态跳变各有一次性外显注入（巧思4 同规格），幅度吃 grudge_inertia：**进入收束句**（"……算了，当我没说过"）、**释怀句**（"上次的事，翻篇了"——全机制情绪回报率最高的一句，没有它哄好与没哄好不可区分）、**超时自我消化句**（"跟你计较这个，我也挺没劲的"）。原则：**转折外显、坡道渐变、幅度吃人格**——用户必须能看着怨恨长出来，而不是被通知它存在。

## 与好感回路的隔离边界

- **只读不改**评估核心：状态机消费 EvalResult（+trigger_hit/repair_signal 两个向后兼容字段），不碰打分
- clamp 改按状态查表 `get_clamp(state)`——8e60a90 的具名常量即查表键，正常态 byte 级不变
- 疏远态独立落库字段（幂等迁移、双端注册）；互斥优先级：疏远 > 沉默 > 撤回，同轮只表达一种"冷"；疏远中屏蔽离线时刻
- 前端零改动：语气即界面

## 为什么克制不上线

1. **阈值是拍的**，且**剧情内冲突是最大误报源**（本产品用户玩 CP 小说角色，戏里吵架是常态）——P1 影子模式先攒一周触发率+剧情冲突误报样本，数据校准后再咬人。
2. **挫败流失未定价**。留存换真实感的汇率没测出来前不押注；Still Face 证据表明做对了反而深化依恋，但"做对"需要数据定义。
3. **它动好感核心回路**。前八个巧思全是外围注入零回滚成本；这个改 clamp 语义+落库+状态机，是唯一"错了不能一键撤"的改动。护城河的终点——从"蒸馏得像"到"相处得真"——值得等数据齐了再走。

**结论：设计冻结归档，P1 影子模式为解冻条件。克制本身是这个设计的一部分。**
